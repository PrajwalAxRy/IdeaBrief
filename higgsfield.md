# Higgsfield media log

Code-drawn UI fragments are always the default for product surfaces. This file
tracks the exceptions — spots where the verdict was that a real photo or video
asset would do a meaningfully better job, and generation via Higgsfield is
still pending.

Each entry: the page/surface, a short description of the image/video wanted
(and why a code fragment isn't the right call there), and the prompt to use
when generating it. Until an entry is generated, its spot in the UI stays a
labeled slot — never a blank div, never deleted.
